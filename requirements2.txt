1. Ingestion & File Parsing (Python Core) 
	Automated Processing: The pipeline monitors a directory or batch-loads files (PDFs, .md, .txt).
	Intelligent Chunking: Rather than cutting off mid-sentence, the Python parser intelligently splits text by logical boundaries (e.g., headers, paragraphs, or semantic sections) while keeping metadata (like file source, chapter, character names, or tags) intact.

2. Vector Embedding Engine (AI/ML Layer)
	Each text chunk is passed through an embedding model (such as OpenAI's text-embedding-3 or a open-source model via Hugging Face/Sentence-Transformers).
	The model converts human language into high-dimensional numerical vectors that capture the meaning behind the text rather than just matching exact keywords.

3. Vector Database Storage (Data Engineering / Tooling)
	Embeddings and their raw text/metadata are stored in ChromaDB (local/lightweight) or Pinecone (cloud/production).
	The database indexes these vectors so that top-$K$ nearest neighbor searches execute in milliseconds.

4. Retrieval-Augmented Generation (RAG Output)
	When queried, the system converts the user's prompt into a vector, calculates vector similarity (e.g., cosine similarity), and returns the most semantically relevant chunks.
	These chunks are dynamically inserted into an LLM context prompt to generate grounded, context-aware responses about your world.
